# ITZ FIZZ Hero Scroll Animation

A pure frontend assignment project built with HTML, CSS, and JavaScript using GSAP for smooth intro and scroll-driven motion.

## Run locally

```bash
cd /home/sama/Downloads/new
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

This project is ready to deploy to GitHub Pages by pushing the workspace to a GitHub repository and enabling GitHub Pages from the repository settings.
